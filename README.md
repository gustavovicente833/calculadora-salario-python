# Calculadora de Salário em Python

Projeto acadêmico desenvolvido em Python para calcular o salário líquido a partir do salário bruto, considerando descontos de INSS e Imposto de Renda.

## Funcionalidades

* Entrada de múltiplos salários
* Cálculo do desconto de INSS
* Cálculo do Imposto de Renda
* Cálculo do salário líquido
* Organização dos salários em ordem crescente
* Exibição dos resultados em formato de tabela
* Geração do arquivo `CALCULOS.txt` com os resultados

## Conceitos utilizados

* Funções
* Estruturas condicionais (`if`)
* Estrutura de repetição (`while`)
* Listas
* Dicionários
* `sorted()` e `lambda`
* Entrada de dados com `input()`
* Manipulação de arquivos
* Formatação de strings

## Tecnologia

* Python
